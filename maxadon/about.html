About Maxadon

Maxadon is a new Web Browser developed by IO Studio that supports the Blink tag and allows Iframes to open all websites like the Electron <webview> tag.

Maxadon has Usable speed and has 2 new Web Standards that Google Chrome doesn't have.

The New Web Standards are the following:

  • The Blink tag (Yes It's back in Maxadon!)
  • Iframes that can open all Websites.

Extra Details

Maxadon is based on Electron which is based on Chromium but Maxadon wasn't created by Google.

To help you stop using Google, Maxadon uses Yep as it's Default Search Engine.

* Maxadon was NOT created by Yep or Ahrefs.
